# Ecosystem Portfolio

The canonical portfolio source for Rylee Benson / Ecosystem Global Solutions Inc.

## Local development

```bash
npm install
npm run dev
```

## Deployment boundary

Vercel must build from the `SelfMadeSE/ecosystem-portfolio` repository. The previous static output directory is deliberately not a runtime or deployment dependency; see [the canonical rebuild audit](docs/2026-08-27-canonical-rebuild-audit.md).

## Media

Media provenance and publishing boundaries are maintained in `public/media/manifest.json`. The founder portrait is an explicit placeholder until an approved final asset is supplied.
